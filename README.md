# gomemt

## 概要
このプログラムはただメモリを確保し開放する様子をログとして吐き出すだけのプログラムです。
表示形式や間隔の変更はソースコードを変更してください。**※変更方法を参照**

## 変更方法
コメントに従い分からない場合はご自分で検索するなり誰かに丸投げするなりして変更してください。

## ビルド方法
例に使用した環境: RockyLinux9. 必要な物: git, go.
1. 配置したいフォルダ内部でgitを使用してcloneします。
```
git clone github.com/ka012c/gomemt
```

2. goを使用しbuildします。
```
go build -o gomemt .
```

3. バイナリファイルに実行権限を与えます。
```
chmod +x gomemt
```

4. 実行します。
```
./gomemt
```

5. これらはすべて例であり環境によって異なります。
